# Default hands-free and guided gesture onboarding

Hands-free now defaults on, including for users with a previously saved disabled preference. The enable/disable checkbox and public setter have been removed. Starting the companion still requires an explicit user action; opening the app does not enable the camera or speak. Camera Pause remains available. Buttons, typing and an explicitly enabled keyboard shortcut remain fallbacks; starting hands-free no longer automatically requests the global keyboard hook.

Onboarding has seven steps. After personal lip-reading training, a new required gesture lesson teaches: resting position; nod for yes/confirm; turn and return for the next choice; shake for no/cancel; nod to start a phrase; mouth a practice sentence and nod to finish; a short resting/mouthing calibration. Recognition of each gesture uses the same HandsFree engine and local MediaPipe face samples as the live companion. Demo gestures never call recognition, voice, calendar or email services. The practice sentence is checked for mouth movement, not transcribed. No video is recorded or uploaded in this lesson.

The final onboarding screen is unlocked after gesture practice. Successful calibration saves the existing hands-free movement threshold and head/nod preferences and a per-profile practice completion receipt. The receipt records completion; it does not claim to train the lip-reading adapter or learn new head thresholds. Runtime head gesture thresholds remain the teammate implementation. Changes synchronize to another widget window. While gesture practice owns the camera, an expiring cross-window lease pauses the widget's gesture actions, avoiding unintended speech from practice nods. The lease renews during practice and clears on exit; it expires after 15 seconds if that window disappears unexpectedly.

My voice & practice includes Practice hands-free gestures, opening a dedicated lesson without repeating voice enrollment or model training. Missing face-model and camera errors offer recovery instead of pretending practice succeeded. Gesture coaching has a bounded animation and a reduced-motion alternative. Optional eyebrow/eye gestures and automatic mouthing-start remain under widget preferences; there is no hands-free off switch.

The face model is now prepared by dependency asset setup and npm run dev if absent. Downloads are bounded to 30 seconds and written atomically. A failed download does not prevent using buttons or typed speech. The existing npm run fetch:face-model command remains available for recovery. Packaged builds include the downloaded public asset when built after successful setup.

No tests, builds, typechecks, previews, app launches, live camera trials or verification passes were run, per the user's standing instruction. Changes remain on a local feature branch until publishing is requested.
